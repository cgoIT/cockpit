# Sicherheit

Sitewatch ist der einzige von außen erreichbare Teil der Installation, und der Agent kann (mit freigegebenen Aktionen) Befehle auf dem Server ausführen. Schwachstellen bitte **nicht** als öffentliches Issue melden.

- Meldung per E-Mail an kontakt@cgo-it.de oder über „Report a vulnerability“ im Reiter Security dieses Repositorys (GitHub Security Advisories).
- Bitte Version (`sitewatch version`, `sitewatch-agent -version`), betroffene Komponente und eine Beschreibung zum Nachstellen mitschicken.
- Es gibt keine feste Antwortzeit; der Betrieb läuft als privates Projekt. Eine Rückmeldung versuche ich zeitnah zu geben.
- Unterstützt wird jeweils die neueste Version.
